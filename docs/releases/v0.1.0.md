# htopModern v0.1.0

First public release of the cozy macOS terminal dashboard.

## Install

```sh
brew install TerrifyGary/tap/htopmodern
htm
```

The Homebrew formula supports Apple Silicon and builds from source. Rust and macmon are installed as dependencies.

## Included

- CPU meters, hardware/system details, top-three processes with PID, and no-sudo CPU/GPU temperatures.
- Generated Fireplace, Beach, and Coffee Shop animations with a flip-style clock.
- Apple Music track info, playback buttons, spinning CD, equalizer, and progress indicator.
- Celsius weather, humidity, hourly precipitation probability, automatic daylight, cached readings, and an animated landscape.
- Persistent todos and five saved color themes; F2 cycles themes.
- Responsive panels with aligned dividers, short `htm` launcher, and MIT license.

## Compatibility and limitations

Tested on Apple Silicon with macOS 26.6.2. Other macOS versions are not all verified. Intel/Linux are not supported by this initial formula. Native weather images depend on terminal graphics support; half-block fallback is automatic. Apple Music requires macOS Automation permission. Firefox/YouTube playback, synchronized lyrics, and configurable tmux prefixes are not included. Equalizer bars are decorative rather than audio-reactive. Weather requires internet access; sensor availability depends on macmon and macOS.

## Validation

Rust tests, formatting, lint checks, release build, and command-line smoke checks passed. Homebrew installation validation is recorded with the tap. Live weather and password-free temperature retrieval were verified on the development Mac. The app has not been certified across every supported terminal or Mac model.
